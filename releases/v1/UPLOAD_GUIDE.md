# Version 1 upload guide

Final release tag: v1.0.0. DOI: 10.5281/zenodo.24500468 (reserved, not confirmed published or publicly accessible). The exact final main commit is reported separately to avoid a self-referential commit hash.

Upload these files from this directory to both the GitHub release and Zenodo:

- Memory_Under_Interference_v1.pdf
- Memory_Under_Interference_v1_source.zip
- Memory_Under_Interference_v1_reproducibility.zip
- SHA256SUMS.txt (SHA-256 hashes of the upload assets)

Use zenodo-metadata-draft.json to populate/review the reserved Zenodo record; use RELEASE_NOTES_V1.md for the GitHub release body. PUBLICATION_READINESS.md records the checks and disclosed scientific limitations. SHA256SUMS.json is the inner file manifest, also inside the reproducibility archive. Licences, notices, raw-response derivatives and numerical sensor samples are inside that archive.

No record or GitHub release is published by these commands. Publish only after author approval. The existing public v1.0.0 GitHub release has an older tag target and no uploaded assets at preparation; update/retarget only with approval. Do not treat the reserved DOI as registered or publicly accessible.
