# Methods and population audit

Recorded settings: `observed-model-settings.json`. Frozen-job field equality:
`schedule-audit.json`. Recorded block-start host/process snapshots:
`environment-block-audit.json`. These files are generated by
`analysis/memory_audit/{provenance,environment}.py`, not recalled estimates.

Both model tags are qwen2.5-coder:0.5b and qwen2.5-coder:1.5b. Model digests
are preserved per job. Registered quantization is Q4_K_M. Recorded CPU is the
Intel i5-13420H; approximately 16 GB RAM; Windows 11; Python 3.13.7; Ollama CPU
execution, eight threads, num_gpu=0. Saved block-start checks observe AC and
Best performance. These checks do not prove no intervening host-state change.
Calls were sequential and the frozen schedule randomized/interleaved conditions.

Energy: HWiNFO CPU Package Power, nominal 500 ms logging, trapezoidal
integration. Start-of-block idle subtraction is primary. Post-load windows are
approximate; total request windows are also retained. Energy is a CPU-package
estimate, not whole-laptop electricity or a calibrated measurement of a single
process. Baseline drift stays flagged; all alternate dispositions are separate.

Correctness uses the frozen EvalPlus HumanEval+ base/expanded partitions and
restricted subprocess evaluator. A pass requires both partitions. Code never
runs in the audit's main process. Primary extraction, test tolerances and oracle
definitions are preserved. HumanEval/32 has the documented oracle anomaly;
exclusion is a sensitivity. Caps are nonpasses under the bounded output endpoint,
not evidence of intentional giving up. API/input/infrastructure failures are
reported separately. Logical calls are distinct from retries in starts/responses.

## E0: isolated prompt-strategy reference

164 tasks, two strategies P1/P3_1, three samples per model: 1,968 logical calls.
Temperature 0.2; context 8,192; output budget 2,048. P1 explicitly requests code
only; P3_1 adds an external worked example with different wording. This tests
two strategies, not the isolated causal effect of adding an example. The sample0
P1 outcome supplies noisy held-out eligibility labels; samples1/2 are outcomes
for eligibility-conditioned E0 sensitivity. Primary E0 uses all three samples.
No other experiment's isolation estimate is substituted by the selecting sample.

## Initial M3: selected-task context-load study

20 held-out-eligible tasks per model, potentially different between models.
Six loaded cells: total prompt lengths 1,000/4,000 tokens, middle target, three
filler types. 240 loaded calls plus 40 fresh no-filler isolation calls, context
8,192, temperature0, output2,048. Exact baseline wrapper/settings match the grid.
The original near duplicates are weaker renamed-specification distractors; this
population/construction must not be pooled with revised semantic M3/R2. A
100-call generation-only checkpoint preceded scoring, under the order amendment.

## M1: passive load, active bundles and token-matched neutral controls

The original fixed 40-task roster is shared by both models. K={2,3,4,6}, three
modes, 960 loaded requests plus 80 isolated controls: 1,040 full calls. Context
32,768, temperature0. Passive and neutral requests generate the focal function
with output2,048; active requests generate K functions with output2,048*K.
Companion descriptions and target placement are fixed. Input matching compares
passive task descriptions to neutral filler; active mode adds requested work.

Report focal correctness, every requested function and all-functions success.
Each active bundle is compared with the same members' saved isolation outcomes.
Those isolation outputs are reused; their summed costs are counterfactual
lookup totals, not new measurements. All membership graphs are connected, so
there is no independently replicated component-level uncertainty estimate.
The separate 70-call diagnostic pilot is excluded from main estimates.

## R1: five context-retention policies

40 tasks × five policies × two models =400 full calls; pilot50 separate.
Context16,384, temperature0, output2,048. Full history places the target before
eight fixed distractor descriptions, with a code-only preference between history
blocks and the final query. Replay repeats the target near the query. No-history
keeps target/query but omits the explicit preference. Oracle selective retention
keeps target+preference+query. Lossless compaction keeps that target wording with
redundant formatting removed and drops distractor history. It is not semantic
summarization of the conversation. Oracle selection has privileged relevance
information; automated retrieval was not evaluated. Instruction, length and
position changes are documented; no naturally exact token-matched policy pairs.

## Revised M3/R2: computationally different competing specifications

40 fixed tasks, two models, three filler types, filler-token targets1,000/2,000,
target beginning/end:960 loaded calls plus80 matched isolation calls. Context
16,384, temperature0, output2,048. Unlike initial M3, these lengths describe
filler rather than total prompt length. The entire prompts need not match.

Near duplicates change a computational requirement while retaining a similar
interface. References and distinguishing cases were validated; the model sees
descriptions only, never the distractor solution or hidden tests. Related and
irrelevant fillers are authored controls, not calibrated similarity levels.
Cross-score target and alternative suites, including isolation/irrelevant/related
outputs, to distinguish alternative-consistent failures from generic failures.
Invalid/capped outputs stay separate. Diagnostic pilot130 is not pooled.

## M2: constructed return-to-task interference

Four loaded conditions—neutral, similar alternative, one other task, three other
tasks—on40 tasks/two models, plus80 exact-setting isolation controls:400 full
calls; pilot50 separate. Context16,384, temperature0, output2,048. Loaded complete
inputs match token counts; target, final instruction and output budget match.
Histories are static task descriptions/acknowledgements, not actual prior task
execution. Similarity and interruption count are not fully crossed. Interpret as
constructed conversational interference, not real behavioral task switching.

## E5: preference placement, not the earlier urgency-framing proposal

40 tasks × five conditions × two models =400 full calls; pilot50 separate.
Context8,192, temperature0, output2,048. Conditions no-preference, immediate,
buried, replayed, corrected share distractor descriptions and target/query.
Original adherence demands unfenced parseable code with the target function.
It remains primary. Posthoc audits separately inspect fences, outside prose,
comments/docstrings and joint correctness. Syntax features do not automatically
measure semantic adherence to the user's preference.

## E4: partial synthetic prefix-cache feasibility evidence

Prefix0/500/1,000/2,000/4,000 × cold/warm × two models ×20 repeats planned400
measured calls. Revised full run saved76; its separate schema pilot saved20.
The earlier unconstrained pilot stopped at10/20 after one response ended short.
Do not combine these workload versions or infer coding pass rates from them.

Context16,384, temperature0, intentional64-token synthetic JSON-array endpoint.
Both measured states keep the model resident. Native cached-token counters,
schema preparation, priming and residency checks distinguish prefix reuse from
residency. Controls are logged but outside measured-request energy. Matching
uses prefix/model/repeat; most cells have zero or one matched pair, so planned
cache inference remains unfinished. A setup-only paused intent is not a77th
completed generation. E3 and U-family experiments have no observations here.

## Statistical and publication boundaries

Task-level bootstrap:2,000 draws, seed1732. Keep repeated seeds/cells paired
within tasks. Binary outcomes use exact McNemar; repeated-cell means use exact
paired sign swaps. Holm families and analysis labels are attached to results.
Pointwise intervals and adjusted tests answer different uncertainty questions.
M1 intervals are conditional on fixed companions; E4 uses repeat variability.
No calibrated sensor errors, independent bundle replication or human annotation
is invented. Two quantized models, one benchmark and one CPU constrain scope.
The study measures observed context utilization behavior and computation, not
internal cognition, recognition, intentional refusal or memory capacity.
