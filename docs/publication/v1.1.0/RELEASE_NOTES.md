# Memory Under Interference — Manuscript Version 1.1 (package v1.1.0)

This release contains the approved final manuscript, corresponding LaTeX source,
standalone reproducibility archive and SHA-256 manifest. The 13-page manuscript
uses embedded Times New Roman, compatible mathematical typography and monospace
code. Scientific findings, evidence and uncertainty are unchanged.

The exact four asset files are preserved from approved commit
`43ab2a71ab1436ce397d44f528645254943e6a9e`. The release targets the verified
publication commit containing only subsequent repository-facing metadata and
handoff documentation. Existing v1.0.0 and v1.0.1 history remains intact.

## Assets

- `Memory_Under_Interference_v1.pdf`
- `Memory_Under_Interference_v1_source.zip`
- `Memory_Under_Interference_v1_reproducibility.zip`
- `SHA256SUMS.txt`

The reproducibility archive contains sanitized saved-response evidence, exact
configurations/prompts, scoring records, numerical power/time samples, analysis
code, figures and integrity manifests. It supports saved-data reanalysis rather
than model-output regeneration, independent correctness rescoring or sensor
calibration. Original multi-sensor mirrors are excluded; numerical CPU-package
streams are supplied. Source compilation requires licensed installed Times New
Roman; no Microsoft font files are distributed. See the archive README and
BUILDING.md for commands and requirements.

**Reserved Zenodo DOI:** [10.5281/zenodo.24500468](https://doi.org/10.5281/zenodo.24500468).
The DOI is reserved; Zenodo publication, registration and public accessibility

This is a preprint, not a peer-reviewed publication. The post-hoc finding remains
censoring-sensitive; retention energy comparisons are estimated and confounded,
with accuracy preservation unresolved. MemoryGraph remains a companion prototype
with separate synthetic retrieval evidence, not an evaluated end-to-end benefit.
